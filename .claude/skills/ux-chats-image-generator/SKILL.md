# UX Chats visual creation

Before creating a visual, read the repository-root `BRAND-GUIDELINES.md` and the relevant poster guidance in `ux-chats-app/imagery-system/`. Use the cited Community Night or Special Guest references for the appropriate format. Follow the current preference for a clear heading and a less busy composition.

Use the official logo assets identified in the guide, preserving their proportions. Never ask an image generator to redraw the logo or render essential text: add the actual logo and accurate heading in a deterministic composition step. Use real, authorized guest portraits and verified event details. Inspect the final image at feed size, check contrast and crop, and provide meaningful alt text.
