# Source Material

Real UX Chats content pulled from Jacki's Obsidian vault (`05-Brand/`, `02-Projects/the-ux-chats_marketing/`) — the raw posts, event listings, and emails that `examples.md` draws from and lightly adapts. Kept here, separate from the skill's own reference docs, so the source stays traceable and there's a larger pool to mine for future copy than what fits in a few-shot file.

Every quote in `../examples.md` and `../voice-and-tone.md` can be traced to one of these files. When adapted (trimmed for length, exclamation-stacking dialed back to match the writing rules), the file says so.

- **`linkedin-posts.md`** — real LinkedIn posts, unedited except for trimming.
- **`luma-events.md`** — real Luma event listings and email blasts.
- **`site-copy.md`** — real production copy already live on theuxchats.co, useful as CTA/spotlight material.
- **`metadata.md`** — canonical links, logo file paths (already in this repo), brand color tokens, and founder/host names — one stop-shop so nobody has to guess a URL or hunt for a logo.

Pulled 2026-08-20. If you add new real posts/events over time, append them here rather than starting a new file.
